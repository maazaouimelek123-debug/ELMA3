# ELMA3 — website

**Designed by you. Made by ELMA3.**

ELMA3 is a clothing brand built around one idea: **customization**. Customers pick a premium
blank piece (a tee, hoodie, crewneck, tote or cap), then design it themselves in the browser
with **ELMA3 Studio**: garment color, text, graphics and stickers, their own photos, front and back.
Then they add it to the bag and order it.

The site is plain **HTML + CSS + JavaScript**: no framework, no build step, no npm packages.
Its look follows the design language of apple.com: big confident type, generous white space,
pill buttons, a translucent blurred navigation bar, rounded tiles and smooth scroll-in animations.

---

## Open the site

**Option 1: double-click.** Open `index.html` in Chrome, Edge, Safari or Firefox. Everything works
straight from disk.

**Option 2: local web server** (closer to how it behaves once online). In this folder run:

```
python -m http.server 8123
```

Then visit **http://localhost:8123**.

> The fonts load from Google Fonts. Offline, the site falls back to your system fonts and still works.
>
> Your bag and saved designs are stored separately for each way you open the site: a `file://` page
> and `http://localhost:8123` do not share a bag.

### Prices and currency — Tunisian dinars (TND)

All prices are in **Tunisian dinars**. 1 dinar = 1000 millimes, so money is kept to 3 decimals.

| What | Where | Current value |
|---|---|---|
| Product prices | `js/garments.js` → `products[].basePrice` | Tee 59 · Hoodie 129 · Crewneck 109 · Tote 39 · Cap 45 |
| Customization extras | `js/garments.js` → `PRICING` | text +8 · sticker/graphic +10 · own image +15 · back print +12 (once) · XXL +6 |
| Delivery price | `js/common.js` → `CONFIG.shipping` | 8 (anywhere in Tunisia) |
| Free delivery from | `js/common.js` → `CONFIG.freeShippingThreshold` | 150 (order value after promo) |
| Promo codes | `js/common.js` → `CONFIG.promoCodes` | `ELMA3` −10 %, `WELCOME` −15 % |
| Price format | `js/common.js` → `CONFIG.currencyLabel`, `currencyPosition`, `currencyDecimals`, `decimalSeparator`, `groupSeparator` | `'DT'`, `'suffix'`, `3`, `','`, no-break space |

Write prices as plain numbers in dinars (`59`, `12.5` for 12 dinars 500 millimes). Every price on the
site is printed by `ELMA3.formatPrice()` (in `js/common.js`), so a change in those settings shows up
everywhere — home tiles, shop cards, Quick Look, the Studio, the bag and the About FAQ. It builds the
text itself (it does not use the browser's `Intl` currency output, which differs between browsers
for TND):

| Call | Result | Used for |
|---|---|---|
| `formatPrice(59)` | `59,000 DT` | bag lines, subtotal, discount, delivery, total, order recap |
| `formatPrice(1290)` | `1 290,000 DT` | thousands are separated by a no-break space |
| `formatPrice(-5.9)` | `−5,900 DT` | true minus sign |
| `formatPrice(129, { compact: true })` | `129 DT` | marketing prices: "From 129 DT", tiles, cards, the Studio total, free-delivery notes |
| `formatPrice(12.5, { compact: true })` | `12,500 DT` | compact keeps the millimes when there are any |
| `formatPrice(6, { compact: true, sign: true })` | `+6 DT` | extras such as the XXL upcharge |

The space before "DT" is a no-break space, so an amount never wraps onto two lines. All money math
(discounts, delivery, totals) is rounded to millimes with `ELMA3.roundMoney()`.

**Another currency?** Change `currency`, `currencyLabel`, `currencyPosition`, `currencyDecimals` and the
separators in `CONFIG` (e.g. euros: `'EUR'`, `'€'`, `'suffix'`, `2`, `','`, no-break space), then the
prices in `js/garments.js`.

**Tax.** `taxRate` is a fraction (`0.08` = 8 %). A value above 1 is read as a percent (`8` = 8 %).

## Important notes

- **Checkout is a front-end demo.** No payment is taken and no order is sent anywhere. To sell for
  real, connect a payment / e-commerce provider (for example a hosted checkout) to the bag page.
- **Bag and saved designs live in the browser's `localStorage`** (keys `elma3.bag.v1` and
  `elma3.designs.v1`). They stay on that one browser and device, and clearing site data empties them.
  If storage is full (large uploaded photos), the bag keeps the item and drops its preview image;
  if storage is disabled entirely, the site shows a message instead of failing silently.
- **Replace the placeholders before launch:** the contact email `hello@elma3.com`, the social links,
  Privacy, Terms and Gift card links (they point to `#`; until then a click shows a small
  "Coming soon." message instead of jumping to the top), and any placeholder copy such as shipping
  times, FAQ answers and product details.
- The `dev/` folder is for development and is not linked from the site. It can be left out when
  you publish.

## Links between pages (deep links)

Every page understands these URLs. Use them for buttons, emails or ads. Unknown ids are ignored
safely: the page simply opens in its normal state.

| URL | What it does | If the id is unknown |
|---|---|---|
| `customize.html?product=hoodie&color=onyx` | Starts a blank design on that piece and color | Default piece / its first color |
| `customize.html?template=varsity` | Opens a ready-made template (ids in `ELMA3.templates`); add `&color=sand` to change its color | Opens the Studio as usual |
| `customize.html?design={savedId}` | Opens a saved design | Opens the Studio as usual |
| `customize.html?edit={bagItemId}` | Edits a piece already in the bag (the main button becomes "Update Bag") | Opens the Studio as usual |
| `customize.html#piece`, `#color`, `#design`, `#templates`, `#size`, `#summary` | Scrolls to that Studio step (`#templates` also opens the template list) | Stays at the top |
| `customize.html#size-guide` | The Size step with the size guide open | — |
| `shop.html#tees`, `#hoodies`, `#crewnecks`, `#accessories`, `#all` | Filters the product grid | Shows all pieces |
| `about.html#story`, `#craft`, `#process`, `#faq`, `#contact` | Scrolls to that section | Stays at the top |
| `about.html#faq-shipping` (also `-returns`, `-sizing`, `-care`, `-printing`, `-uploads`, `-editing`, `-payments`) | Opens that FAQ answer | Stays at the top |
| `index.html#how` | The "How it works" section | — |

Parameters can be combined with a section, e.g. `customize.html?template=noor#size`. Arriving at a
`#section` from another page jumps straight there; clicks on in-page links scroll smoothly.

## Building or changing a page

Open **`dev/styleguide.html`** to see every available style and component. Every page uses this
`<head>` (see any existing page). The Google Fonts stylesheet loads without blocking the first
paint; system fonts show until it arrives:

```html
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">
<title>Page title — ELMA3</title>
<meta name="description" content="One sentence about the page.">
<meta name="theme-color" content="#ffffff">
<link rel="icon" href="assets/favicon.svg" type="image/svg+xml">
<script>document.documentElement.classList.add('js');</script>
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet" href="{FONTS_URL}" media="print" onload="this.media='all'">
<noscript><link rel="stylesheet" href="{FONTS_URL}"></noscript>
<link rel="stylesheet" href="css/base.css">
<link rel="stylesheet" href="css/{page}.css">
<script src="js/garments.js" defer></script>
<script src="js/common.js" defer></script>
<script src="js/{page}.js" defer></script>
```

(`{FONTS_URL}` is the Google Fonts address used by every page — copy it from an existing page.)
And this `<body>`:

```html
<body data-page="shop">                 <!-- home | shop | customize | about | bag -->
  <a class="skip-link" href="#main">Skip to content</a>
  <div id="globalnav-root"></div>       <!-- the nav is injected by common.js -->
  <main id="main"> … </main>
  <div id="globalfooter-root"></div>    <!-- the footer is injected by common.js -->
</body>
```

- Pages in a subfolder (like `dev/`) add `data-base="../"` to `<body>` so nav and footer links work.
- Add `data-reveal` to any element to fade it in on scroll (`data-reveal="fade"`, `="scale"`,
  and `data-reveal-delay="1"`–`"4"` for staggering).
- Add a product sub-navigation with `<nav class="localnav">` (see the style guide). The global nav
  then scrolls away and the sub-nav sticks, as on apple.com.
- On pages without a sub-navigation, the global nav turns dark by itself while a black section
  (`.section--dark`, `.section--dark-alt`, or any element with `data-nav-theme="dark"`) is under it.
- A link with `href="#"` is treated as "not ready yet": clicking it shows "Coming soon.".

### Shared JavaScript helpers (`window.ELMA3`, from `js/common.js`)

| Helper | What it does |
|---|---|
| `ELMA3.config` | Shop settings (see above) |
| `ELMA3.formatPrice(59)` | `"59,000 DT"` — Tunisian dinars with millimes (bag lines, totals, checkout) |
| `ELMA3.formatPrice(59, { compact: true })` | `"59 DT"` — for marketing prices like "From 59 DT" (millimes are kept when there are any); add `sign: true` for `"+6 DT"` |
| `ELMA3.roundMoney(n)` | Round an amount to millimes (3 decimals) — use it for any price math |
| `ELMA3.qs(sel, root)`, `ELMA3.qsa(sel, root)` | `querySelector` / `querySelectorAll` (as an array) |
| `ELMA3.escapeHTML(str)` | Make text safe to put inside HTML |
| `ELMA3.onReady(fn)` | Run code once the page is ready |
| `ELMA3.store.get/set/remove` | Safe JSON `localStorage` (never throws; `set` returns `false` on failure) |
| `ELMA3.store.available()` | `false` when the browser blocks storage entirely (the Studio and bag then show a notice) |
| `ELMA3.bag.items/add/update/remove/clear/count/subtotal/get/summary` | The shopping bag. Fires `elma3:bagchange` on `window`. Adding a piece that is already in the bag raises its quantity |
| `ELMA3.designs.all/get/save/remove` | Saved Studio designs. Fires `elma3:designschange` |
| `ELMA3.promo(code)` | `{ code, percent }` for a valid promo code, else `null` |
| `ELMA3.toast(msg, { tone, actionLabel, actionHref, onAction, duration, focusAction })` | Small notification at the bottom of the screen. Toasts with an action (Undo…) stay up while the visitor uses the keyboard; `focusAction: true` moves focus to the action |
| `ELMA3.announce(text)` | Screen-reader announcement |
| `ELMA3.reveal(root)` | Activate scroll animations on newly added `data-reveal` elements |
| `ELMA3.openModal(dialog)`, `ELMA3.closeModal(dialog)` | Open / close a `<dialog class="modal">` with animation |
| `ELMA3.lockScroll(true / false)` | Stop / restore page scrolling behind an overlay |
| `ELMA3.bindPaddles(scroller, paddleNav)` | Wire the ‹ › buttons of a horizontal gallery |
| `ELMA3.syncRange(input)` | Refresh a `.range` slider's blue fill after changing its value in code |
| `ELMA3.url(href)` | Prefix a link with the page's `data-base` |

From `js/garments.js`: `ELMA3.normalizeDesign(design)` repairs any design loaded from storage or a
URL (drops images that can't display, caps each side at `ELMA3.limits.layersPerSide` layers and
text at `ELMA3.limits.textLength` characters); `ELMA3.priceFor(design)` prices it.

## Browser support and accessibility

Works in current versions of Chrome, Edge, Safari and Firefox, on desktop and phones (tested down to
375 px wide). The site is keyboard accessible with visible focus rings, uses semantic HTML and ARIA
labels, and turns off all motion when the visitor's system asks for reduced motion.
